# 🚀 JOVI Smart Cam

Projeto de uma Smart Cam desenvolvida para a JOVI, com foco em tecnologia, praticidade e integração com o ecossistema de dispositivos da empresa.

A proposta do projeto é apresentar uma solução de câmera inteligente com uma interface web simples e organizada, permitindo demonstrar as principais funcionalidades da Smart Cam de forma intuitiva.

---

## 📱 Sobre o projeto

A JOVI Smart Cam foi desenvolvida como parte de um projeto acadêmico voltado para a criação de uma solução tecnológica para a empresa JOVI.

O sistema utiliza uma aplicação web para apresentar e controlar as funcionalidades propostas para a Smart Cam, utilizando uma interface pensada para ser simples de entender e fácil de utilizar.

O projeto também teve como objetivo aplicar na prática conhecimentos de desenvolvimento web, organização de componentes e criação de interfaces.

---

## 💡 Objetivo

O principal objetivo do projeto é desenvolver uma interface para uma câmera inteligente, buscando unir tecnologia e facilidade de uso.

A aplicação foi pensada para permitir que o usuário tenha acesso às principais funções da Smart Cam de maneira organizada, com uma experiência simples e intuitiva.

---

## 📦 Instalação

Para executar o projeto localmente, é necessário ter o Node.js instalado.

Com o projeto aberto no terminal, execute:

```bash
npm install
```

Esse comando irá instalar as dependências necessárias para executar a aplicação.

---

## ▶️ Executando o projeto

Após a instalação das dependências, execute:

```bash
npm run dev
```

O terminal irá informar o endereço local da aplicação.

Acesse o endereço informado pelo terminal através do navegador.
